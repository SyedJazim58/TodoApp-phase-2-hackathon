# Debugging & Quality Assurance Skill

## Instructions

1. **Project execution**
   - Run the application locally
   - Verify environment setup and dependencies
   - Identify startup/runtime errors

2. **CRUD verification**
   - Test Create, Read, Update, Delete flows
   - Validate edge cases and invalid inputs
   - Ensure state consistency

3. **API testing**
   - Test endpoints using curl/Postman
   - Validate request/response schemas
   - Check status codes and error handling

4. **Code review & debugging**
   - Identify logic, syntax, and performance issues
   - Trace errors using logs and stack traces
   - Suggest spec-aligned fixes (no manual coding)

## Best Practices

- Reproduce issues before fixing
- Debug from spec → behavior → code
- Validate fixes against acceptance criteria
- Prefer minimal, spec-driven changes
